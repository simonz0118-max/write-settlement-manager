## 启动
Mac 双击 `start.command`，浏览器打开 `http://localhost:4173`。

## 已完成
- 稳定流式导入 `.xlsx` / `.zip`，继续规避超大 Sheet XML 内存爆炸。
- 只忽略 `FACT` Sheet，不忽略同工作簿中的真实订单 Sheet。
- 订单号去重。
- 自动识别：铅笔、雕刻服务、普通笔芯、彩色笔芯、礼盒、礼品卡、B2B。
- `🎁` / `100% off` 自动标记为赠品。
- 订单级会计分类为互斥分类，因此分类金额可以直接相加并与总订单金额对账。
- 商品级分类用于商品件数/赠品件数统计；不把订单金额强行分摊到每件商品。
- 未识别商品保留为“待确认”，同时生成待复核清单，避免错误硬分类。
- 一键导出 `.xlsx`，包含：`会计汇总`、`订单明细`、`商品分类明细`、`导入日志`。
