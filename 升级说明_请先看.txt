WRITE Settlement Manager V7.1.10 升级说明

V7.1.10 = 自适应订单结构学习。

目标：
以后遇到以前没有见过的订单 Excel，系统先尽量全自动识别。
如果订单号 / 金额 / 产品名称 / 国家等核心字段置信度不够，只弹一次字段映射确认。
确认后的结构永久写入本地 IndexedDB，并在有网络时自动同步到 Cloudflare D1。
以后同类表格（包括列顺序变化）直接自动识别。

使用：
1. 解压 ZIP。
2. 双击“一键更新到GitHub并部署Cloudflare.command”。
3. 等待 [1/9] 到 [9/9] 全部通过。

注意：
“尽量全自动”不等于允许静默猜错。
系统不能证明核心字段正确时，会阻止错误报表/FACT输出并要求一次确认。

V7.1.10 特别修复：V7.1.9 发布前生成 worker 的字面量 \\n 语法错误；本版从 GitHub V7.1.8 干净基线重新构建。
