WRITE Settlement Manager V7.0.1 正式升级包

【最简单的升级方法】
1. 解压整个 ZIP。
2. 双击「一键更新到GitHub并部署Cloudflare.command」。
3. 等待终端依次显示：
   [1/4] 获取 GitHub 最新 main
   [2/4] 同步当前版本
   [3/4] GitHub 更新完成
   [4/4] Cloudflare Pages 部署
4. 最终看到“V7.0.1 升级完成”即可。

【如果 macOS 第一次阻止脚本】
右键脚本 → 打开 → 再点“打开”。

【正式网站】
https://write-settlement-manager.pages.dev/

【说明】
- 发布脚本每次都会先 clone GitHub 最新 main，因此不会再出现 fetch first / non-fast-forward。
- 正式 ZIP 不包含 .git，不携带旧 Git 历史。
- 中文脚本文件名使用 UTF-8 ZIP 元数据，并在发布前验证。
- 完整更新历史见 CHANGELOG.md；网页左侧“历史更新”和首次打开更新弹窗同步维护。
