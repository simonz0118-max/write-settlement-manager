WRITE Settlement Manager V7.1.8 升级说明

这是 V7.1.7 → V7.1.8 的 Cloudflare Pages Functions 路由修复包。

直接：
1. 解压 ZIP。
2. 双击“一键更新到GitHub并部署Cloudflare.command”。
3. 不要手动改文件。

本版新增：
- 根 _routes.json：只让 /api/* 进入 Pages Functions
- 发布前先编译 functions
- 编译结果必须证明 /api/rules/sync 存在
- 部署后必须：
  1) 唯一 pages.dev deployment
  2) data-release=v7.1.8
  3) GET /api/rules/sync HTTP 200
  4) JSON ok:true
  5) D1 Binding 实际可用

如果 API 再失败，终端会直接显示 HTTP 状态和响应正文，不再只显示一个 curl 404。

不会修改结算、FACT、订单、会计、规则学习和本地 IndexedDB 业务核心。
