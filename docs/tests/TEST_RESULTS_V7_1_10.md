# V7.1.10 深度自检

## 目标
把“学习”从商品/FACT PRICE 扩展到订单表结构，尽量实现陌生订单 Excel 全自动识别；只有核心字段置信不足时才要求一次确认。

## 真实样本分析
本版本设计参考用户上传的 `归档(1).zip`。样本内同时包含：
- 5 个 XLSX 工作簿
- FACT 成本工作表
- 多个真实订单工作表
- 额外的产品统计 Sheet
- 多商品换行
- SKU `*数量`
- 多国家订单
- 不同规模订单表

已抽样得到的真实订单规模包括 17、16、270、523 条订单行，商品数量存在单件与多件组合。

## V7.1.10 核心
- 表头 alias + 列数据特征联合推断
- 50 行范围内自适应寻找表头
- 核心字段：orderId / orderAmount / productNames / country
- productCount 缺失可自动推导
- 高置信自动使用并学习
- 中置信弹一次字段映射
- 人工确认写入 ORDER_SCHEMA
- ORDER_SCHEMA 进入现有 IndexedDB
- 联网自动通过 `/api/rules/sync` 同步 Cloudflare D1
- 同 fingerprint 或同表头高重合结构直接复用

## 安全门
系统不会为了“任何表格都导入”而静默猜错。核心字段不完整或置信不足时，禁止进入最终统计/FACT/会计输出，先要求确认。

## 保留
订单统计、FACT 模板逻辑、FACT 自动学习、数量守恒、会计结算、未知商品过滤、商品规则、FACT PRICE、离线模式、主题和历史更新保持。
