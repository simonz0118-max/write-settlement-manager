WRITE Settlement Manager V10.3.1 — 紧急完整性修复

1. 修复 V10.3.0 FACT 清理正则跨行匹配导致整张正式发票数据被删除的严重错误。
2. FACT 底部管理统计改为逐行精确定位后删除，绝不再触碰正式发票行。
3. 商品汇总不再使用会重复计算 SKU 数量/服务行的旧会计统计，改为直接使用生产结算引擎去重后的 productSalesSummary。
4. 首页/结算总览的“商品件数、赠品件数、待复核订单”与生产结算结果统一。
5. 待复核不再出现“成本不完整但显示 0”的矛盾状态；按 needsReview 对应真实订单去重统计。
6. 数据管理菜单：主动断开 V10.2.9 的旧 MutationObserver，删除旧样式锁，固定为单一 ⌘ + 数据管理 标签。
7. 数据管理搜索栏、表格列宽、操作按钮重新锁定，避免截断、重叠和字体漂移。
8. 保持 D1 云端学习、人工审核学习、CN-only、跨设备同步以及多商品单包裹运费逻辑不变。
