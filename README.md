# WRITE Settlement Manager v5.0

Local-first settlement and accounting classification web app for real order Excel / ZIP files.

## V5 highlights

- Refined light macOS-inspired interface.
- Photo-detailed line-art panda profile brand asset.
- Large hero export CTA for the accounting workbook.
- Fast re-import action directly from the dashboard.
- Streaming XLSX parser retained for pathological large workbooks.
- FACT worksheets are ignored at sheet level; order sheets are detected by structure.
- Deduplication, accounting classification, product classification, gift detection and review queue retained.
- No colorful pie chart; classification is presented with a sortable table and subtle share bars.
- Professional six-sheet Excel export: overview, orders, product summary, review, audit, import log.
- One-click GitHub and Cloudflare Pages update scripts for macOS.

Production URL: https://write-settlement-manager.pages.dev/
